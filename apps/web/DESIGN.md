# UI design notes

- Shell: mineral teal `#123f3c`; cool white work surface `#fff`; cool gray-green navigation `#edf2f2`.
- Text: platform system sans stack, dark ink `#172e32`, supporting text `#63777b`.
- Status: reserved green for connected/available; amber marks accepted receipt; rust denotes access/network errors.
- Controls use standard platform shapes, visible keyboard focus, explicit labels, restrained borders, and a narrow-screen conversation-first layout.
- These are initial implementation tokens, not a user-approved brand identity.
